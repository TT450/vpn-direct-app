# Support

Thanks for using VPN Direct.

## Before opening an issue

1. Check the latest [release notes](WHATS_NEW.md) and [CHANGELOG](CHANGELOG.md).
2. Confirm whether the feature is listed as production-ready in the [Protocol Matrix](docs/core/PROTOCOL_MATRIX.md).
3. Never paste private keys, subscription tokens, or real server credentials.

## Where to go

| Need | Place |
| --- | --- |
| App discussion / bot | [Telegram @vpndirectbot](https://t.me/vpndirectbot) |
| Bug in this client / Core bridge | [GitHub Issues](https://github.com/TT450/vpn-direct-app/issues) |
| Feature request | [Feature request template](https://github.com/TT450/vpn-direct-app/issues/new/choose) |
