# VPN Direct — Haptic Audit

В приложении используется единый тактильный словарь из `HapticManager.swift`.
Экран не выбирает силу вибрации самостоятельно: он сообщает смысл события,
а движок воспроизводит стабильную сигнатуру и применяет throttling.

## Тактильный язык

| Событие | Ощущение | Где используется |
| --- | --- | --- |
| `touchDown` | Очень мягкое короткое касание | Все SwiftUI-кнопки |
| `navigation` | Лёгкий уверенный импульс | Табы, переходы, возврат |
| `selection` | Системный selection tick | Сервер, тариф, способ оплаты, режим |
| `toggleOn` / `toggleOff` | Нарастающая / затухающая пара | Все переключатели |
| `sheetPresented` / `sheetDismissed` | Открытие / закрытие слоя | Серверы, отчёт, профили, восстановление |
| `swipeThreshold` | Точный rigid tick | Порог 44 и 128 pt во время свайпа |
| `vpnConnecting` | Три нарастающих импульса | Старт защищённого канала |
| `vpnConnected` | Яркая восходящая финальная сигнатура | VPN подключён, отчёт защиты |
| `vpnDisconnecting` | Два затухающих импульса | Начало отключения |
| `vpnDisconnected` | Мягкая финальная точка | VPN отключён |
| `vpnSwitching` / `vpnSwitched` | Перебор маршрута / подтверждение | Сервер, подписка, failover |
| `adStarted` / `adCompleted` | Старт / зачёт просмотра | Rewarded-реклама |
| `rewardGranted` | Четырёхчастная reward-сигнатура | +1 час и +200 МБ |
| `purchaseStarted` / `purchaseCompleted` | Подтверждение оплаты | Apple / внешний checkout |
| `copied`, `shared`, `saved`, `imported` | Короткое подтверждение результата | Журнал, отчёт, правила, URL |
| `warning`, `error`, `deleted` | Различимые служебные ответы | Опасные настройки, валидация, сброс |

## Покрытие взаимодействий

- Главная: проверка сети, режим, Free-доступ, VPN-кнопка, выбор сервера.
- Навигация: бургер, затемнение меню, три способа импорта, нижние вкладки.
- Серверы: закрытие, поиск/сброс, вкладки, автовыбор, каждая локация.
- Подписки: Free/Premium/URL, активация, детали, тарифы и ресурсы.
- Реклама: начало, ответ просмотра, третья реклама, начисление и подключение.
- Оплата: выбор способа, начало checkout и успешная активация.
- Профиль: каждый пункт, предупреждение системного раздела, возвраты.
- Настройки: все Toggle/Picker, журнал, copy/share, импорт, очистка,
  сброс туннеля, On Demand, сохранение и ошибки.
- Модальные экраны: показ, закрытие, drag/swipe thresholds, failover.

## Защита от лишней вибрации

- Персональный debounce для каждой сигнатуры.
- Глобальный предел частоты для каскадных обновлений состояния.
- Системный fallback на `UIFeedbackGenerator`, если Core Haptics недоступен.
- `CHHapticEngine` создаётся только на совместимом устройстве и автоматически
  останавливается в простое.
- Общий переключатель «Тактильная отдача» находится в
  «Настройки → Приложение» и сохраняется через `AppStorage`.
- Клавиатурные нажатия не дублируются: за них отвечает системная настройка iOS.

## Подключение реальной бизнес-логики

Сетевой слой должен вызывать семантические события только после фактического
ответа: `.loading` при начале, `.imported`/`.saved` при успехе, `.warning` для
восстановимого ответа и `.error` для отказа. VPN-адаптер вызывает
`vpnConnecting`, `vpnConnected`, `vpnDisconnecting`, `vpnDisconnected`,
`vpnSwitching` и `vpnSwitched` из своего state machine — UI не должен угадывать
результат по таймеру в production-коде.
